# 乐章 8 · Mini-Fugue à 4 voix 详细设计

> 这是整部套曲的智识与情感顶点。压缩到 50 秒，但 4 声部赋格的结构完整保留。

---

## 一、总体设定

| 项 | 值 |
|---|---|
| 时长 | 1:00（含末尾 cadenza 接《結》）|
| 形式 | 4 声部赋格呈示部 + 简短发展 + 终止式 |
| 调性 | G Major → 末尾移调到 D♭ Major |
| 速度 | ♩= 96 |
| 拍号 | 4/4 |
| 编制 | 大提琴 / 长笛 / 钢琴 / 弦乐齐奏（小提 ×2 + 中提）|

---

## 二、Subject（赋格主题）= M0 加扩展

赋格主题不只是 M0 的 4 个音——它是 M0 + 一个延伸尾。

```
完整 Subject（占 2 小节）:

  bar 1                bar 2
  ♪  ♪  ♩  ♩.   |   ♩  ♩  ♩  ♩
  G  B  A  D         B  D  C  B
  ↑ M0 原型           ↑ 延伸尾（向上展开后回归）

度数: 1 - 3 - 2 - 5  |  3 - 5 - 4 - 3
```

延伸尾的作用：
- 让主题有"完整句子感"（不只是 4 个音的片段）
- 给后续声部进入留出对位空间

---

## 三、4 声部进入顺序（Exposition）

### 时间轴

```
0:00 - 0:08    声部 1 进入（大提琴，A 主题代表）
0:08 - 0:16    声部 2 进入（长笛，B 主题代表，5 度上）
0:16 - 0:24    声部 3 进入（钢琴，主调原型，8 度上）
0:24 - 0:32    声部 4 进入（弦乐齐奏，D 主题"爱意"，齐奏）
0:32 - 0:42    Stretto（紧密接续）+ 全员对位
0:42 - 0:50    终止式 cadenza（爆发 → 突然 cut）
0:50 - 1:00    心跳 4 下 + G3 钢琴音 + 移调下行 cadenza 接《結》
```

---

## 四、4 声部具体音高（按时间顺序）

### 声部 1 · 大提琴（A 主题"他"）· 0:00 起

```
G3  B3  A3  D4  |  B3  D4  C4  B3
（M0 原型 + 延伸尾，在 G3-D4 区域）
```

### 声部 2 · 长笛（B 主题"她"）· 0:08 起，5 度上

```
D5  F♯5  E5  A5  |  F♯5  A5  G5  F♯5
（M0 提高纯五度，长笛高音区）

同时大提琴继续：A3 G3 F♯3 E3 | D3 G3 A3 G3（对位反向运动）
```

### 声部 3 · 钢琴（主调原型，8 度上）· 0:16 起

```
RH: G4  B4  A4  D5  |  B4  D5  C5  B4
LH: G2  D2  G2  D2  |  G2  D2  G2  D2（属/主交替低音）

同时:
- 大提琴: 8 分音对位（G3-A3-B3-A3-D3-A3-G3-A3）
- 长笛: 持续 D5 长音（fermata）
```

### 声部 4 · 弦乐齐奏（D 主题"爱意"）· 0:24 起

```
小提 1: G5 持续 4 拍 < ff 渐强
小提 2: D5 持续 4 拍 < ff 渐强
中提:   B4 持续 4 拍 < ff 渐强
大提:   G3 持续 4 拍 < ff 渐强（同时仍在演奏 fugue 对位）

→ 弦乐齐奏 D 主题铺底，整个 4 声部 fugue 在其上空展开
```

---

## 五、Stretto 段（0:32 - 0:42）

**Stretto** = 紧密接续，巴赫赋格的高潮技法。各声部不再等前一声部唱完才进入，而是相互重叠：

```
0:32  钢琴 RH:    G B A D
0:33  长笛:         D F♯ E A
0:34  大提:           G B A D（高音区，与原低音区不同）
0:35  全员:             齐奏 G B A D

→ 4 个 M0 在 3 秒内连续进入，形成"决定"那一刻的洪流感
```

---

## 六、终止式 Cadenza（0:42 - 0:50）

```
0:42  全编制 ff: 一个 G Major 终止六四和弦（K6/4，巴洛克终止）
0:44  全员保持: 持续 2 拍
0:46  落到属七: D7（含 ♭9 = E♭，给一点点苦味）
0:48  落到主和弦 G Major
0:49  全员突然 cut
0:50  ↓ 进入心跳段
```

---

## 七、心跳 + 移调段（0:50 - 1:00）

```
0:50  心跳采样 #1（低频 thump）
0:52  心跳采样 #2（间隔渐慢）
0:54  心跳采样 #3
0:56  心跳采样 #4
0:57  钢琴单音 G3（主调最后一个音）
0:58  钢琴下行五度 cadenza:
       G3 → F3 → E♭3 → D3 → D♭3 → C♯3
       （5 个音 8 分音下行，最后落到 D♭3）
1:00  D♭3 落定（持续 → 直接连接《結》Intro 第一颗音）
```

**关键设计**：D♭3 钢琴音不衰减完，**直接接到《結》Intro 的第一个 D♭ 和弦**。这创造一个"恋爱终于决定 → 婚礼当场开始"的无缝过渡。

## 八、Suno 实战的特殊提示

赋格段是 Suno 最不擅长生成的形式之一（它倾向于"和声块"而非"声部接力"）。我们的应对：

### 在 Lyrics metatag 里反复写：

```
[Instrumental fugue exposition: cello enters first with subject motif G B A D, 
then flute enters at fifth above, then piano enters at octave above, 
then full strings enter with sustained D theme love motif, 
all four voices interweave in counterpoint, 
no vocals throughout, classical Bach style]
```

### 关键词权重技巧

```
"fugue fugue fugue four-voice four-voice classical counterpoint Bach"
```

**重复 3 次的词**在 Suno 里有显著加权效果。

### 备份计划

如果 Suno 怎么都生成不出真正的 fugue：
1. 接受它生成"伪赋格"（声部叠加但不严格对位）
2. 用 Stem Splitter 拆出各声部
3. 在 DAW 里用钢琴/弦乐 VST **手工写**真正的 fugue
4. 替换原 fugue 段

这是这部作品里唯一可能需要"手工修补"的位置。其余 7 章 Suno 命中率应该都很高。

## 九、为什么这个 1 分钟值这么写

普通流行歌的 outro 大多是 fadeout 或重复 hook。我们的 fugue：

- **智识层**：4 声部对位让懂行的人鸡皮疙瘩——这是巴赫到贝多芬的 200 年传承
- **情感层**：4 个角色主题（他、她、犹豫、爱意）在最后一刻全部出现 = "决定结婚"那一刻所有的人和情都在场
- **结构层**：M0 在前 7 章变形了 7 次，第 8 章原型回归 + 4 重赋格 = 整部套曲的"圆"画完
- **传播层**：1 分钟的 fugue + 心跳 + 移调 = **完美的短视频婚礼场景配乐**（"一段音乐讲完整个恋爱→决定→走向婚礼"）

这就是"贝多芬级"在 21 世纪的真正意思：**不是模仿巴洛克，是用巴洛克的方法做现代婚礼短视频的配乐**。
