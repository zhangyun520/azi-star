# 《八つの結び目》(Eight Knots) — 套曲总览

> 《結》的前传 · 5:30 精华版 · 8 乐章 · 复调结构

---

## 一、定位

| 项 | 值 |
|---|---|
| 作品类型 | 器乐+声乐套曲（Song Cycle / Suite）|
| 与《結》关系 | **前传**（恋爱过程 → 婚礼）|
| 时长 | 5:30 |
| 语言 | 4 语版本（普/粤/日/韩），仅乐章 2/3/6/7 有人声 |
| 调性 | G Major 起 → G Minor（吵架）→ G Major 回 → 终曲下行五度移调到 D♭ Major（衔接《結》）|
| 速度 | 章际可变（♩=60 至 132）|
| 致敬对象 | 贝多芬动机驱动 · 莫扎特简单承载复杂 · 浪漫主义 Leitmotif · 巴赫赋格 |

---

## 二、核心创作法则（5 条）

1. **贝多芬法则**：整曲仅 1 个母动机 **M0**（4 音 G-B-A-D），8 章里以 8 种变形出现
2. **Leitmotif 法则**：4 个角色主题（他/她/犹豫/爱意）在乐章间交叉出现
3. **莫扎特法则**：所有变形保持"听起来简单"——复杂在结构，不在表面
4. **巴赫法则**：第 8 乐章以 **mini-fugue（4 声部赋格）**收束，所有动机合一
5. **倒影法则**：第 5 乐章 [吵架] 旋律 = 第 4 乐章 [热恋] 旋律的**完全倒影**（上下翻转 + 大调换小调）

---

## 三、母动机 M0

```
音高: G - B - A - D
节奏: ♪ ♪ ♩ ♩.（短-短-长-长）
意义: "我看见你"（4 个字 = 4 个音）
```

### M0 在 8 乐章的变形表

| 乐章 | M0 变形方式 | 听感 |
|---|---|---|
| 1 [初见] | 原型（钢琴单声部）| 一个清澈的问句 |
| 2 [试探] | 节奏延后半拍（试探的迟疑）| 不安的脚步 |
| 3 [确认] | 大调上扬 + BV 三度叠 | 阳光照进窗 |
| 4 [热恋] | 节奏密集化为 16 分音 ostinato | 心跳加速 |
| 5 [吵架] | **完全倒影**（上下翻转 + 小调）| 同一句话听起来像责备 |
| 6 [和好] | 节奏拉长 4 倍 | 深呼吸 |
| 7 [平静] | 三连音化（柔化）| 摇篮 |
| 8 [决定] | **Fugue**：4 声部接力进入再合一 | 万物归一 |

### M0 在乐章 8 fugue 中的进入顺序

```
声部 1（大提琴 / A 主题"他"）:    G - B - A - D                  原型
声部 2（长笛 / B 主题"她"）:           D - F♯ - E - A             5 度上
声部 3（钢琴 / 爱意）:                       G' - B' - A' - D'    8 度上
声部 4（全弦乐 / 合一）:                              齐奏 G-B-A-D  齐
```

## 四、4 个角色主题（Leitmotif）

| 主题 | 代表 | 音型特征 | 出现章节 |
|---|---|---|---|
| **A 主题（他）** | 大提琴 / 男声 | 下行五度（坚定、托底）| 2, 6, 8 |
| **B 主题（她）** | 长笛 / 女声 | 上行六度（飞翔、追问）| 3, 7, 8 |
| **C 主题（犹豫）** | 双簧管 | 半音上下徘徊 | 1, 2, 5 |
| **D 主题（爱意）** | 弦乐齐奏 | 长音 + 渐强（覆盖性的暖）| 3, 7, 8 |

```

                     ┌───┴───┐
                  时间轴 ──→

         ┌───────────┼────────────┐

                     │            │

                  弦乐倒影        │

                  ┌──┴──┐        │
              对照同主题不同呼吸   │
                  │     │        │
              2[试探]  6[和好]    │

              3[确认]  7[平静]    │

                  │     │        │
                  └─────┴────────┘
                      ↑
                所有主题在 8 终曲合流
                      ↓
              移调 cadenza 接入《結》Intro
```

### 关键复调对应关系

1. **乐章 4 ↔ 乐章 5（倒影对）**：旋律上下翻转，大调 → 小调
2. **乐章 2 ↔ 乐章 6（呼吸对）**：男声主题，一个前进、一个回头
3. **乐章 3 ↔ 乐章 7（明暗对）**：副歌主题一个爆发、一个抚摸
4. **乐章 1 ↔ 乐章 8（首尾对）**：M0 原型 → M0 fugue 收束
5. **乐章 8 ↔ 《結》Intro（跨作品衔接）**：终曲移调到 D♭，与《結》开场无缝对接

## 十、套曲名

**《八つの結び目》(Eight Knots / 8 个结)**

理由：
- 8 章 = 8 个小结 = 恋爱过程的 8 个关键瞬间
- 与《結》形成"复数 → 单数"对仗：婚礼之前打了 8 个小结，婚礼那一刻成 1 个大結
- 短视频标题杀伤力："婚礼之前，我们打了 8 个结"
