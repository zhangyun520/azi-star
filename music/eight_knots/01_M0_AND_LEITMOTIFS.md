# M0 母动机与 Leitmotif 详细谱

> 这是整部套曲的"DNA 图谱"。所有作曲、编曲、Suno 生成都从这两件事派生。

---

## 一、M0 母动机 · 标准型

### 音高与节奏

```
拍号: 4/4
速度: ♩= 标准（可变化，但比例不变）

  bar 1 |  ♪    ♪    ♩    ♩.    |
        |  G    B    A    D     |
           1    3    2    5     ← 度数（在 G Major 中）
```

### 在五线谱上的位置

```
高音谱表：
       ────────────────────
       ────────────────────
       ────D───────────D───  ← D5
       ──A─────────────────  ← A4
       ────B───────────────  ← B4
       G───────────────────  ← G4
       ────────────────────
```

### 度数分析（为什么是这 4 个音）

| 音 | 度数 | 在 G 大调里的功能 |
|---|---|---|
| G | 1（主音）| 安全、起点 |
| B | 3（中音）| 大调色彩、温暖 |
| A | 2（上主音）| 紧张、未解决 |
| D | 5（属音）| 强烈的"问号" |

**情感解读**：从主音出发 → 探出大调温暖 → 退回上主音紧张 → 落到属音问号 = "我看见你 + 一个未问出的问题"。

## 二、M0 在 8 乐章的具体变形

### 乐章 1 [初见] · 原型

```
节奏: ♪ ♪ ♩ ♩.
音高: G4 B4 A4 D5
速度: ♩= 60，rubato
出现次数: 4 次（分别在 0:03 / 0:12 / 0:22 / 0:30）
特征: 每次出现间隔越来越短——心跳加速的暗示
末次悬挂: 第 4 次最后一个音 D5 持续到不解决，进入 sus4
```

### 乐章 2 [试探] · 节奏延后半拍

```
原型节奏: ♪ ♪ ♩ ♩.
变形节奏: ♩ ♩ ♩. ♩.（每个音延后半拍，更"踌躇"）
音高: 不变 G B A D
速度: ♩= 96
角色: 钢琴左手以 8 分音重复 M0 的延后节奏型 = 试探的脚步
```

### 乐章 3 [确认] · 大调上扬 + BV 三度叠

```
节奏: 原型 ♪ ♪ ♩ ♩.
音高: G B A D（主声）+ B D C♯ F♯（BV 三度上）
速度: ♩= 108
角色: 副歌 hook 的真正"诞生"——M0 第一次以"完整明亮"形态出现
```

### 乐章 4 [热恋] · 16 分音 ostinato

```
原型: ♪ ♪ ♩ ♩.（4 个音占 1 小节）
变形: GBAD GBAD GBAD GBAD（4 组 16 分音占 1 小节）
速度: ♩= 132
角色: 钢琴左手 16 分音 ostinato = 心跳加速
听众: 完全意识不到这是 M0，但耳朵记住了
```

### 乐章 5 [吵架] · 完全倒影

```
原型音高: G  B  A  D    （+0  +4  +2  +7 半音）
倒影音高: G  E♭ F  C    （-0  -4  -2  -7 半音 → 上下翻转）
节奏: ♪ ♪ ♩ ♩.（不变）
调性: G Minor
角色: 同一节奏型，听起来变成完全相反的情感
这是结构层面的诗
```

**倒影计算**：以 G4 为对称轴，每个音上方距离 = 倒影音下方距离
- B4（G 上方 +4 半音）→ E♭4（G 下方 -4 半音）
- A4（G 上方 +2 半音）→ F4（G 下方 -2 半音）
- D5（G 上方 +7 半音）→ C4（G 下方 -7 半音）

### 乐章 6 [和好] · 节奏拉长 4 倍

```
原型: ♪ ♪ ♩ ♩.（约 1 小节）
变形: ♩.♩.♩.♩.（占 4 小节，每个音延音 4 倍）
速度: ♩= 72
调性: E♭ Major（远关系调，"换了个房间说话"）
角色: 大提琴慢慢"叹"出 M0 = 道歉的缓慢
```

### 乐章 7 [平静] · 三连音化

```
原型: ♪ ♪ ♩ ♩.
变形: 3 连音化为 (3:♩) ♩ ♩ ♩.（柔化）
速度: ♩= 84
调性: G Major（回主调，但更深）
角色: 长笛吹出柔化版 M0 = 摇篮
```

## 三、4 个 Leitmotif 详细谱

### A 主题（他）· 下行五度

```
代表乐器: 大提琴
代表声部: 男声
基本音型: D5 - G4（下行纯五度）
节奏: ♩ ♩.（坚定的两拍）
情感: 坚定、托底、男性的承诺感

变形:
- 乐章 2: D5 - G4 - A4（试探时多一个上行小二度，问号）
- 乐章 6: D5 - C5 - B4 - A4 - G4（道歉时变成阶进下行 5 个音）
- 乐章 8 fugue 第 1 进入: 标准型 D5 - G4
```

### B 主题（她）· 上行六度

```
代表乐器: 长笛
代表声部: 女声
基本音型: G4 - E5（上行大六度）
节奏: ♩. ♩（轻盈的飞翔）
情感: 飞翔、追问、女性的好奇

变形:
- 乐章 3: G4 - E5 - F♯5（确认时多一个上行小二度，欣喜）
- 乐章 7: G4 - E5 - D5（平静时多一个下行小二度，安顿）
- 乐章 8 fugue 第 2 进入: A 主题 5 度上 = D5 - F♯5 - E5（移调）
```

### C 主题（犹豫）· 半音徘徊

```
代表乐器: 双簧管（也可单簧管）
基本音型: A♯4 - B4 - A4 - B4（半音上下来回）
节奏: ♩ ♩ ♩ ♩（均匀的不安）
情感: 不确定、徘徊、犹豫

出现章节:
- 乐章 1: 在 M0 原型 4 次之间作为"间隙呼吸"
- 乐章 2: 持续穿插于钢琴脚步之间
- 乐章 5: 放大到主导地位（吵架时犹豫胜出）
```

### D 主题（爱意）· 长音渐强

```
代表乐器: 弦乐齐奏（小提×2 + 中提 + 大提）
基本音型: G3 - G4 - G5 - G6（4 个八度齐奏，长音持续 4 拍）
力度变化: pp < mf < f（渐强）
情感: 覆盖性的暖、不可抗拒的爱意

出现章节:
- 乐章 3: 副歌高潮处首次完整呈现（pp → f）
- 乐章 7: 同样位置但反向（f → pp，"安静的最高潮"）
- 乐章 8 fugue 末尾: 全编制齐奏 D 主题 = 爱意覆盖一切
```

## 五、给作曲/Suno 提示词的关键概念词

当我们写 Suno 提示时要重复这些技法关键词，提高动机贯穿的命中率：

```
"recurring four-note motif G B A D throughout all sections"
"motif appears in inverted form in fifth section"
"motif as ostinato in fourth section"
"four-voice fugue exposition in finale, motif passed between cello flute piano strings"
"two recurring leitmotifs: descending fifth (he) and ascending sixth (she)"
"third theme of chromatic hesitation on oboe"
"fourth theme of long string chord swells representing love"
```

这些英文术语 Suno 训练数据里非常密集（古典音乐数据集占比高），命中率很高。
